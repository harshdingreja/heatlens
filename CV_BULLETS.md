# CV bullets (numbers from RESULTS.md)

- Built **HeatLens** on SIH 2026 PS #26083 (MoES): forecasts Mumbai heat stress 1–5 days ahead by correcting 4 global weather models with a linear + LightGBM model, cutting heat-index error from **3.75 °C to 1.45 °C (−61 %)** on an unseen 2026 test set and raising recall on "Danger" days from **0.45 to 0.92** (F1 0.61 → 0.81); added z-score + IsolationForest anomaly detection and SHAP explanations.
- Mapped heat vulnerability across **24 BMC wards** from 55 Landsat 8/9 scenes (LST + NDVI) and Census 2011 data into a vulnerability index (equal vs PCA weights, ρ = 0.99) with k-means clustering (k = 4), matching the city climate plan's ward heat data (**Spearman ρ = 0.93**); served via FastAPI + React with an evidence-based excess-death estimate and LLM advisories in English, Marathi and Hindi.
